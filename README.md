# Wids2026
I learned the fundamentals of machine learning, deep learning, and PyTorch through the weekly resources provided, including introductory materials on neural networks, attention mechanisms, and transformers. This helped me understand how models learn from data and how PyTorch is used to build and train neural networks.

After gaining this foundational knowledge, I implemented a Bigram Language Model as part of the WiDS mid-term assignment. The model predicts the next character based only on the current character, without any memory of previous inputs, which results in funny and nonsensical text generation.
